# Gyro Mouse (TV par kuch install nahi karna)

Phone Bluetooth mouse + keyboard ban jata hai. TV ise normal Bluetooth mouse samajhta hai.

1. Phone par app install karo, Bluetooth permission allow karo.
2. "Phone ko discoverable karo" dabao.
3. TV: Settings -> Remote & Accessories -> Add accessory. Phone ka naam aayega, pair karo.
   (Ya phone ki Bluetooth settings se TV ko pair karo.)
4. App me list me TV par tap karo -> Connected.
5. Pad dabake rakho aur phone ghumao -> cursor chalega. Sirf tap = click.
