# Gyro Cursor (TV par asli mouse cursor, phone gyro se)

Do app: phone (Gyro Mouse) aur tv (Gyro Cursor TV). GitHub Actions dono APK banata hai.

TV par install ke baad:
1. TV app kholo -> IP aur PIN dikhega.
2. Accessibility me "Gyro Cursor" ON karo
   (ya adb: settings put secure enabled_accessibility_services com.example.gyrocursor.tv/com.example.gyrocursor.tv.CursorService
        settings put secure accessibility_enabled 1)
3. Phone app me IP + PIN daalo -> Connect.
4. Pad dabake rakho aur phone ghumao -> cursor chalega. Sirf tap = click.
